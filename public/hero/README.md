# キービジュアルのポスター画像

生成したポスター画像をここに置く。

## 手順

1. 画像をこのフォルダに置く。ファイル名は `poster-{言語コード}.png`
   （例: `poster-ja.png`。言語コードは ja / en / ko / zh / es / pt）
2. `lib/site.ts` の `heroPoster` に、その言語のエントリを追加する
   （コメントアウトされた雛形があるので、外して寸法を実際の値に直す）

## 画像の要件

| 項目 | 値 |
|------|-----|
| 比率 | 縦長 4:5 |
| 幅 | 1080px 以上（表示は最大 860px なので、2倍で 1720px あると望ましい） |
| 形式 | PNG または WebP |
| 容量 | 300KB 以下（超える場合は圧縮する） |

## 注意

- 画像に焼き込んだ文字は、検索エンジンにもスクリーンリーダーにも届かない。
  同じ内容の見出しをコード側で併置しているので、画像の主コピーを変えたときは
  `content/ui.ts` の `hero.title1` / `hero.title2` も合わせて直す。
- 画像の中のボタンは押せない。ポスター全体をゲーム一覧へのリンクにし、
  画像の直下に実物のボタンを置いてある。
- エントリを追加していない言語は、実装で組んだキービジュアルが表示される。
  日本語だけ画像、他は組版、という混在で問題ない。
