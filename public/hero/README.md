# キービジュアルのポスター画像

## 現在の構成（日本語）

| ファイル | 役割 | 備考 |
|---------|------|------|
| `poster-ja.png` | 入稿された原本 | 1122x1402 / 2.4MB。**配信には使わない** |
| `poster-ja.webp` | 実際に配信する画像 | 同寸 / 254KB（品質82） |

`lib/site.ts` の `heroPoster.ja` が WebP を指している。

## 他の言語を追加する手順

1. 画像をこのフォルダに置く（`poster-{言語コード}.png`。言語コードは ja / en / ko / zh / es / pt）
2. 300KB 以下の WebP に変換する
3. `lib/site.ts` の `heroPoster` にエントリを追加する

エントリを追加していない言語は、実装で組んだキービジュアルが表示される。
日本語だけ画像、他は組版、という混在で問題ない。

## 画像の要件

| 項目 | 値 |
|------|-----|
| 比率 | 縦長 4:5 |
| 幅 | 1080px 以上 |
| 配信形式 | WebP |
| 配信容量 | **300KB 以下**（原本の PNG をそのまま配信しない） |

## 注意

- 画像に焼き込んだ文字は、検索エンジンにもスクリーンリーダーにも届かない。
  同じ内容の見出しをコード側で併置しているので、画像の主コピーを変えたときは
  `content/ui.ts` の `hero.title1` / `hero.title2` も合わせて直す。
- 画像の中のボタンは押せない。ポスター全体をゲーム一覧へのリンクにし、
  画像の直下に実物のボタンを置いてある。
